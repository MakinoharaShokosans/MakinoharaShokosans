### 🌿 About / 简介

专注于系统工程与底层体验打磨。追求现代软件的简约与秩序，关注自主代码智能体架构、进程级沙箱安全以及高保真 Web 音频流处理。

- 🔭 **Current Focus**：大语言模型自主代码研发框架、本地混合检索（Hybrid RAG）与轻量化隔离沙箱。
- 🎵 **Audio Engine**：基于 TypeScript 的硬件直通（Bit-Perfect）播放流与立体声双耳跨馈算法实现。
- 💡 **Philosophy**：少即是多，保持清晰、专注与自洽的工程实现。
